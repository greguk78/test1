# Tu wrzuć swoje zdjęcia

Układ: **kategoria / seria / zdjęcia**

```
photos/
  lotnictwo/
    Radom Air Show 2026/
      DSC01234.jpg
      seria.json        (opcjonalnie, wzór: przyklad-seria.json)
  motoryzacja/
    Track day Tor Poznań/
      DSC05678.jpg
```

Po dodaniu zdjęć odśwież stronę. Zawartość tego folderu nie trafia do gita.
Zamiast tego folderu możesz wskazać udział na NAS w `portfolio.config.json` (`photosDir`).
